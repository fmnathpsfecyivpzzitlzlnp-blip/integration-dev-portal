poi-5.2.3.jar — Основная библиотека POI, предоставляющая API для создания и управления документами Excel (книга, лист, ячейка).
poi-ooxml-5.2.3.jar — Основной модуль для поддержки современного формата Excel (.xlsx), использующего стандарт Office Open XML.
poi-ooxml-lite-5.2.3.jar — Содержит "чертежи" (низкоуровневые Java-классы), описывающие точную XML-структуру документов формата .xlsx.
xmlbeans-5.1.1.jar — Мощная библиотека для работы с XML, которую POI использует для чтения и записи файлов внутри .xlsx архива.
commons-collections4-4.4.jar — Предоставляет продвинутые и эффективные структуры данных (коллекции), которые POI использует для внутреннего управления информацией.
commons-io-2.11.0.jar — Набор утилит, который POI использует для упрощения операций ввода-вывода, например, для эффективной работы с потоками данных.
commons-compress-1.21.jar — Позволяет POI работать с ZIP-архивами, так как современный файл .xlsx по своей сути является сжатым архивом.
log4j-api-2.18.0.jar — API (набор интерфейсов) для библиотеки логирования, который POI использует для записи своей служебной информации и ошибок.
